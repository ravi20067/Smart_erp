## 1. Overview & Directory Structure

The Python microservice lives in `smart-erp-face-ai`. It serves purely as the Computer Vision inference engine, remaining completely decoupled from student database records, attendance rules, and user authorization.

## 2. Deep Learning Models & Calibration

### A. YuNet Face Detection (`face_detection_yunet_2023mar.onnx`)
- **Input Size**: Dynamically resized to $320 \times 320$ or $640 \times 480$.
- **Outputs**: Bounding box $[x, y, w, h]$, score, and 5 facial landmarks (right eye, left eye, nose tip, right mouth corner, left mouth corner).
- **Confidence Threshold**: $0.70$.
- **NMS Threshold**: $0.30$.

### B. SFace Face Recognition (`face_recognition_sface_2021dec.onnx`)
- **Input**: Aligned face crop generated by YuNet landmarks.
- **Output**: 128-dimensional floating point vector.
- **Normalization**: $L_2$ norm applied to guarantee unit hypersphere projection:
  $$\|v\|_2 = \sqrt{\sum_{i=1}^{128} v_i^2} = 1.0$$
- **Cosine Similarity Threshold**: **$0.363$** (calibrated against OpenCV SFace benchmark; values $\ge 0.363$ represent identical identities).

### C. MiniFASNetV2 Anti-Spoof (`2.7_80x80_MiniFASNetV2.onnx`)
- **Input**: $80 \times 80$ pixel normalized face crop with scale factor $2.7$.
- **Output**: Softmax probability $[P_{spoof}, P_{real}]$.
- **Spoof Rejection Threshold**: $P_{real} < 0.70$ is immediately flagged as a spoof attempt.

### D. Landmark Geometric Head Pose & Blink Estimation
- **Eye Aspect Ratio (EAR)**:
  $$\text{EAR} = \frac{\|p_2 - p_6\| + \|p_3 - p_5\|}{2 \|p_1 - p_4\|}$$
  - Blink threshold: $\text{EAR} < 0.21$ (closed eye); $\text{EAR} > 0.28$ (open eye).
- **Head Pose Estimation (Yaw, Pitch, Roll)**:
  - Computed using `cv2.solvePnP` mapping 5 landmarks to a canonical 3D facial model.
  - `TURN_LEFT`: $\text{Yaw} > +20^\circ$.
  - `TURN_RIGHT`: $\text{Yaw} < -20^\circ$.
  - `LOOK_UP`: $\text{Pitch} > +15^\circ$.
  - `LOOK_DOWN`: $\text{Pitch} < -15^\circ$.
  - `LOOK_STRAIGHT`: $|\text{Yaw}| \le 12^\circ$ and $|\text{Pitch}| \le 12^\circ$.

## 3. Continuous Identity Extraction Workflow

To eliminate the risk of an attacker completing liveness and subsequently uploading a third-party photograph, the microservice implements **Continuous Capture Pipeline**:

1. When a student streams challenge frames to `/api/v1/sessions/{id}/frames`, each frame is processed by `LivenessEngine`.
2. When the current challenge is `LOOK_STRAIGHT` or the face is oriented frontally ($|\text{Yaw}| \le 10^\circ, |\text{Pitch}| \le 10^\circ$) with high detection confidence ($> 0.85$), `FacePipeline.extract_embedding()` runs SFace recognition on that exact live frame.
3. The embedding is stored in the `SessionData.best_embedding` buffer.
4. When `/api/v1/sessions/{id}/complete` is called, the service returns `captured_embedding` (a 128-float array) directly to Spring Boot.
5. Spring Boot immediately compares this embedding against the student's decrypted registered template.

## 4. REST API Contracts

### Health Check
- **`GET /api/v1/health`**
- **Response**:
```json
{
  "status": "healthy",
  "version": "1.0.0",
  "models_loaded": {
    "yunet": true,
    "sface": true,
    "anti_spoof": true
  }
}
```

### Create Liveness Session
- **`POST /api/v1/sessions/create`**
- **Request**:
```json
{
  "challenges": ["LOOK_STRAIGHT", "BLINK_TWICE", "TURN_LEFT"],
  "timeout_seconds": 60
}
```
- **Response**:
```json
{
  "session_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "challenges": ["LOOK_STRAIGHT", "BLINK_TWICE", "TURN_LEFT"],
  "current_challenge": "LOOK_STRAIGHT",
  "status": "IN_PROGRESS"
}
```

### Push Frame Batch
- **`POST /api/v1/sessions/{session_id}/frames`**
- **Request**:
```json
{
  "frames": ["<base64-encoded-jpeg-data>", ...]
}
```
- **Response**:
```json
{
  "session_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "challenge_passed": true,
  "current_challenge": "BLINK_TWICE",
  "liveness_score": 0.96,
  "is_spoof": false,
  "has_captured_embedding": true
}
```

### Complete Liveness Session
- **`POST /api/v1/sessions/{session_id}/complete`**
- **Response**:
```json
{
  "session_id": "9b1deb4d-3b7d-4bad-9bdd-2b0d7b3dcb6d",
  "success": true,
  "captured_embedding": [0.034, -0.082, 0.119, ...],
  "liveness_score": 0.94
}
```

### Compare Embeddings
- **`POST /api/v1/compare`**
- **Request**:
```json
{
  "embedding_a": [0.034, -0.082, ...],
  "embedding_b": [0.035, -0.081, ...]
}
```
- **Response**:
```json
{
  "similarity": 0.784,
  "match": true,
  "threshold": 0.363
}
```

### Enroll Face
- **`POST /api/v1/enroll`**
- **Request**:
```json
{
  "image_base64": "<base64-encoded-jpeg-data>"
}
```
- **Response**:
```json
{
  "success": true,
  "embedding": [0.035, -0.081, ...],
  "dimension": 128
}
```
